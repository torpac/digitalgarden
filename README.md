# Digital Garten

My personal digital garden.

## Gallery and Travel

Gallery: In Pages CMS select "Gallery — picture wall" then New. Upload your picture, add an optional caption and original Pinterest pin URL, choose an order number, and Save. Mixed sizes appear in an uncropped masonry-style layout, with click-to-enlarge viewing.

Travel: In Pages CMS select "Travel — visited countries and map colors". Add country names separated by commas, such as Finland, Turkey, Germany. You can also change ocean, land and highlighted-country colors. Save and GitHub Pages rebuilds.

On the Travel page, click "edit map", click countries, then copy the resulting list and paste into the CMS field. Map-click editing is a preview only until the CMS field is saved. Alternatively tell ChatGPT the countries and it can change the settings in GitHub directly.

World map boundaries come from public-domain Natural Earth data redistributed by the world-atlas package. Simplified small-scale borders may omit very small territories. Only upload pictures you have permission to share; linking an original pin is not a copyright license.
